# The Folders Did It

From the video: "1 Prompt Rebuilt My Entire Content System (Jake Van Clief ICM Folder System)"

## The prompt gets the credit, the folders did the work

Here's the part nobody gets. When I typed that 1 prompt, the AI didn't guess at anything. It went and READ my folders:

- **The map** said where every video lives.
- **The list** already named which 8 lessons still wore the dead brand, written down before the prompt ever existed.
- **The brand law file** said exactly what the new look is: the colors, the font, the ending card, what's banned.
- **The notes** knew the cloud setup, so when Amazon's approval came in mid-run, it knew exactly what to do with it.

1 prompt worked because 41 days of organized folders were the real instructions. If I'd typed the same prompt into an empty folder, I'd have gotten a guess. A confident, wrong guess.

This is Jake Van Clief's ICM folder system doing exactly what he says it should. His methodology, I just run it.

## The 4 files, in plain language

1. **The map.** 1 file at the top that says where everything lives and what should never be touched. Your AI reads it first, every time.
2. **The inventory.** 1 file that lists what you have and what state it's in. Mine listed every lesson and which brand it wore. When the rebrand ran, the shopping list already existed.
3. **The brand law.** 1 file with your look and voice rules, written like laws, not suggestions. Colors, fonts, words you never use, words you always use.
4. **The notes.** 1 file of the stuff you'd otherwise re-explain every session: your tools, your logins' locations (never the passwords), the gotchas you've already learned.

None of this is technical. If you've ever organized a shared drive so a coworker could find things, you've already done the hard part.

## Run this prompt

Paste this into Claude (or any AI):

```
Help me build the 4 files that will make you stop guessing about my business, modeled on the ICM folder system idea: a map, an inventory, a brand law file, and a notes file.

About my business: [what you do, who you serve, what you make content or products about]
Where my stuff lives today: [folders, drives, tools, even "scattered everywhere, honestly"]

Build them 1 at a time, interviewing me as you go:
1. THE MAP: ask me where my important things live, then write a 1-page map file that says where everything is and what should never be touched.
2. THE INVENTORY: help me list my main assets (content, pages, offers) with 1 line each on what state they're in.
3. THE BRAND LAW: pull my rules out of me: colors, fonts, tone, words I always use, words I ban. Write them as laws.
4. THE NOTES: ask what you'd otherwise have to re-learn every time we talk, and write it down.
Keep every file short enough that you can read all 4 at the start of any job. When we're done, tell me the first walk-away job these files would now make safe.
```
