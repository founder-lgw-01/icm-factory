# The Card

Yo! It's RyMac. Read the-desk.md first. This file is the fix.

## Clear the desk off

Instead of a pile, put down **one card, taped to the desk.** Always there. It
never gets cleared off and you never have to go get it.

All the card says is **where everything lives.**

It is not the work. It is not your documents. It is a map. Where's the brand
voice? Third drawer. Where's the pricing? Second drawer.

Then when you actually ask for something, it walks over, pulls the one folder
it needs, sets it on the desk, uses it, and puts it back.

And now the desk never fills up. Because it was never holding everything. It
was holding a map, and one folder at a time.

That is the entire methodology. Folders, plain text files, one card taped down.

## The real names

- **The card** is a file called `CLAUDE.md`. One at the top of your project.
- **A drawer** is just a folder.
- **The folder it pulls out** is a file called `CONTEXT.md` inside that folder,
  which says how to work on that one thing.

That is the translation. Metaphor on the left, filename on the right, and
nothing else to learn.

## What actually goes on the card

3 things. That is it.

1. **What this folder is for**, in one sentence.
2. **Where things live**, as a short list.
3. **What you never want touched.**

That is a real, working card. Not a template you fill out for an hour.

## The mistake I made, with the real numbers

My first card was 146 lines. I thought a better card meant a more complete
card, so I put everything in it: rules, examples, preferences, history.

I had rebuilt the pile. I just moved it onto the card.

Today it is 119 lines and it works better. Because a map is only useful if it
is smaller than the territory. **The card is a table of contents, not the book.**

If your card is getting long, that is not thoroughness. That is the pile
coming back.

## Run this prompt

Paste this into your AI along with this file:

```
Help me write the card for one real folder in my business.

The folder: [WHAT IT IS, e.g. "my client proposals folder"]
What it is for, in one sentence: [YOUR SENTENCE]
What is in it right now: [ROUGH LIST OF FILES OR SUBFOLDERS]
Things I never want changed or touched: [YOUR LIST]

Write me a CLAUDE.md with exactly 3 sections: what this folder is for, where
things live, and what to never touch. Rules:
- Under 40 lines total. If you go over, you are putting the book on the card.
- Every line has to be something an AI would ACT on. No preamble, no
  "this document describes."
- Where a thing does not exist yet but should, say so in one line rather
  than inventing it.
- Plain language. If a 12 year old could not follow it, rewrite it.

Then tell me the 3 things I described that do NOT belong on the card, and
which drawer each one should live in instead.
```

Save the output as `CLAUDE.md` in that folder. That is the whole first move.
