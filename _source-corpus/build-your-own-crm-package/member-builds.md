# Member Builds: the room record

This file is the community's trophy wall. When you build something with the
files in this package and post it in the community, you go in here, name
kept. The record grows with every drop.

Why it exists: seeing a name you recognize next to a real build beats any
testimonial. This community's record started with a member catching a real
bug in video 1 (the missing customer-journey image), which got a whole
re-render. That is the standard: this room ships and this room checks
receipts.

## How to get in here

1. Run a prompt from any file in this package on your own business.
2. Post what came out in the community: the page, the headline set, the
   calculator design, whatever it is. Rough is fine. Shipped beats perfect.
3. Tag the post with which file you used. I read all of it, and builds that
   teach the room something get added here with your name on them.
