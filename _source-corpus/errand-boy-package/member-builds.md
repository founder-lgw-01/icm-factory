# Member Builds

The room record for this drop. When somebody in here runs one of these prompts and
posts what came back, it goes in this file with their name on it.

**From:** Stop Being the Errand Boy Between AI Agents
**Watch it:** https://www.youtube.com/watch?v=En4IeyJ8JoI

---

## How this file works

Post your result in the comments and it gets added here. That is the whole process.

What is worth posting:

- **Your errand boy test result.** Especially if it stung. How many tools were you
  manually feeding, and which one did you kill.
- **Your map.** The one page. Seeing somebody else's is worth more than any
  explanation of what a map should be.
- **Your folder names.** Particularly the ones you named for what gets DONE in
  them. Good names are contagious.
- **Rot you found.** The thing your files still said that was not true anymore. Do
  not be embarrassed. Mine said I sold a brand I had already killed.
- **Where a prompt fell over.** More useful than a win. If it gave you something
  generic, say so and paste what you got, and it gets fixed.
