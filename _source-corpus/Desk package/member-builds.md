# Member Builds: the room record

This file is the community's trophy wall. When you build something with the
files in this package and post it in the community, you go in here, name kept.
The record grows with every drop.

Why it exists: seeing a name you recognize next to a real build beats any
testimonial. This room ships and this room checks receipts. A member catching
something in a video has already caused a full re-render around here, so the
standard is set.

The interesting thing about this package is that the builds are almost
embarrassingly small. A 12 line text file in a folder you already had. That is
the whole entry fee. Post the ugly first version, not the polished one, because
the ugly first version is what everybody else is stuck before.

## How to get in here

1. Run a prompt from any file in this package on a folder you actually use.
2. Post what came out: the card, the drawer names, the thing it told you did
   not belong. Rough is fine. Shipped beats perfect.
3. Tag the post with which file you used.
4. Bonus, and this is the one I most want to see: post the card you wrote in
   week 1 next to the card after you trimmed it. Mine went 146 lines to 119
   and got better. That before-and-after teaches the room more than a
   finished system does.

I read all of it, and builds that teach the room something get added here with
your name on them.
