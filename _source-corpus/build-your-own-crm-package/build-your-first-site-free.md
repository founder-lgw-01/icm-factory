## The 5 steps

1. **Get Claude Code.** It is a program from the company that makes Claude.
   It runs in a terminal, which sounds scary, and then you just type English
   at it.
2. **Make a GitHub account. Free.** Rule 1 of ownership: the code lives in
   YOUR account. Not mine, not a platform's. If everything else disappears
   tomorrow, you still have the code.
3. **Brief it like a contractor.** Tell it what you want built, in English.
   Then, and this is the part nobody tells beginners: you never read the
   code. You open the page in your browser and judge the RESULT. Wrong
   color? Say so. Button feels cheap? Say so. It fixes it. The whole skill
   is describing what you want and complaining accurately.
4. **The magic step: git push.** git saves your code up to your GitHub
   account (Claude Code runs it for you if you ask). Connect GitHub to
   Vercel once, about 3 clicks, free tier. From then on: every push puts
   your site live on a real URL in about a minute. Same deployment pipeline
   professional teams use. Your bill: $0.
5. **Buy your domain,** about $12 a year, and point it at Vercel.

Total: $12 a year. Not $497 a month.

## Run this prompt

Open Claude Code in an empty folder and paste this (fill the brackets):

```
Build me a 1-page website for [WHAT YOUR BUSINESS DOES, e.g. "a mobile
detailing business in Tulsa"].

- Dark theme, modern, fast, no frameworks I have to manage.
- Big claim at the top aimed at [WHO IT IS FOR].
- 3 short sections: the problem I solve, proof or how it works, and a
  contact form at the bottom (name, phone, what they need).
- Mobile-first. No placeholder lorem text, write real draft copy I can edit.

When it is built: open it in my browser so I can look at it, then wait for
my complaints. After I approve it, walk me through putting it on GitHub and
Vercel step by step, one step at a time, assuming I have never used either.
```

Then complain accurately until you love it, and say "git push."
