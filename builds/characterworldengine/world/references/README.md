# references, the images the bibles cite

Put reference images here before running `00_setup`: photos, sketches, earlier
generations, turnarounds. Name them so a bible can cite them, `ref-01.png`,
`ref-02.png`, or by what they show, `mara-face-front.png`.

Setup reads them and every `[stated: <image>]` mark in a bible points at 1 of
them. They stay here for the life of the world so a later reader can check any
trait against its source. Nothing sends them to the image tool.
