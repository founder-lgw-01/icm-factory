# 04-EDIT

Stages 5, 6 and 7. The storyboard from your ACTUAL recording, the 90 second
approval render, then the full render and measured assembly.

- `05-STORYBOARD.md` is built off the real transcript, 1 row per spoken
  sentence. You approve its gate page before anything renders.
- The 90 second approval render comes BEFORE the full length, every time.
- Renders run in the cloud so your machine stays yours. Set that up once,
  before your first video, not during it. The pick is AWS. A new account
  starts with $100 in free credits. A render costs pennies against them.
  The engine is Remotion, and `rymac-build-video-in-code` carries the how.
- Your voice is never cut. Not once, not for a hold, not by a frame.

Skill that runs here: `rymac-edit-and-render-a-video`. It carries the full
7-phase procedure and the 12 laws that bind every frame.
