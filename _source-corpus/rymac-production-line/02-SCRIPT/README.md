# 02-SCRIPT

Stages 1, 2 and 3 happen here, inside each video's own folder under
`production/<video-name>/`.

- `01-GAMEPLAN.md` opens with your LOCKED keyword, hook and title from
  research, plus the lock block: BRAND, SKIN, SURFACE, ENDS-ON, SLUG.
- `02-SCRIPT.md` is numbered slides, never prose. You approve it before
  anything else moves.
- `03-SPEC.md` names the render engine on line 1 and every shot after it. The
  spec is the stage that keeps getting skipped, and skipping it is the most
  expensive mistake on the line.

Skills that run here: `rymac-build-a-youtube-video`,
`rymac-write-a-slide-video-script`, `rymac-write-in-the-owners-voice`,
`rymac-build-video-in-code`.
