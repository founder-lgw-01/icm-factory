# Risk table, shot type to invariants at risk

`01_spec` reads the brief and lists every row that applies under **At risk**,
with the guard for each. Each guard is a concise positive scene fact where 1
exists. The full audit is `drift-checklist.md`, walked after the render; it
is not repeated in the prompt as a catalogue of absences.

| The shot has | At risk | Guard in the prompt |
|---|---|---|
| a profile or 3/4 view | jaw, nose, brow, ear, hairline | state the profile lines from the bible in words |
| a back view | silhouette, hair fall, wardrobe back | describe the back of the hair and garments |
| a full body, wide | proportions, height, hands, relative scale | state build and height in words; name what is underfoot for scale |
| a close-up | eyes, skin tone, marks, hair texture | state each mark and its position |
| fast action or an unusual pose | proportions, limb length, wardrobe state | describe the pose joint by joint and say the outfit stays as listed |
| low light or night | skin tone, hair color, palette | name the light color and say what it does to skin and hair |
| weather or water | hair, wardrobe state, materials | name the wet or wind state the bible allows |
| 2 or more characters | relative scale, signature features swapping between them | name each at first mention with its features; state heights against each other |
| a wardrobe state other than default | every garment in that state | list the state's garments from the bible |
| an expression at the edge of range | face, and out-of-character read | name the expression and what it is not |
| a new location, first time shot | palette, materials, light | freeze the location's applicable facts and the composed view in Scene |
| 2 or more candidate references or families | reference coherence, transfer boundaries | 1 primary reference and 1 dominant family; state what each selected role lends, never the unselected ones |
| a wide city, a complex environment, many landmarks | focal hierarchy and density | name the subject, the destination, and the anchors this frame needs; say the background stays subordinate |
| a visible river, canal, stream, aqueduct, route, or bridge | spatial topology | state the ingress, the course, the egress, and what every bridge crosses |
| a ratio the host does not produce exactly | framing, output dimensions | stop before the render; the operator picks a supported ratio or an explicit crop |
| a concept with a label as its carrier | the label's words, its legibility | quote the words once, in the Concept line, and say where the label sits |
